# Contributing to CalmResume

Thank you for helping improve CalmResume. Please use GitHub Issues to report bugs or suggest improvements before starting a substantial change.

## Pull requests

- Keep changes small, focused, and consistent with the calm visual direction.
- Do not add dependencies without prior discussion.
- Test layouts at 360px, 390px, 768px, 1024px, and 1440px.
- Check A4 print preview when the change affects content or styling.
- Check keyboard navigation, semantic HTML, and accessibility.
- Update documentation whenever behavior changes.

Fork the repository, create a focused branch, make and test the change, then open a pull request with a clear explanation.

## Commit messages

Short descriptive messages are welcome. Conventional Commits are helpful but not mandatory:

- `fix: correct mobile navigation spacing`
- `docs: improve print instructions`
- `feat: add optional resume section`
