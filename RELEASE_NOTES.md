# CalmResume v1.0.0

The first public release of CalmResume, a calm and minimal HTML resume template for thoughtful professionals.

## Highlights

- Responsive one-page resume layout
- Semantic HTML
- Vanilla CSS and JavaScript
- Professional highlights and structured career sections
- Accessible mobile navigation
- A4 print and Save as PDF support
- No framework, dependency, or build process
- MIT licensed

## Getting started

Download the source, replace the placeholder profile data, and open `index.html` directly in a browser.

Live demo:  
https://awekhstudio.github.io/calmresume/
