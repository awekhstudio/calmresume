# Security Policy

CalmResume is a static front-end template. By default, it has no backend and does not collect user data.

To report a security concern privately, contact `security@example.com`.

> Maintainer note: replace the placeholder security email above before publishing the repository.

Do not include sensitive personal information in a public GitHub issue. Users who add scripts, analytics, forms, embeds, or third-party dependencies are responsible for reviewing their security and privacy implications.
