## [1.0.0] - 2026-07-27

### Added

- Semantic single-page resume structure.
- Responsive editorial layout.
- Professional highlights section.
- Experience, projects, education, skills, recognition, and languages.
- Availability and professional details.
- Accessible mobile navigation.
- Print and Save as PDF action.
- A4 print stylesheet optimized for a concise resume.
- Keyboard focus states and skip link.
- Reduced-motion support.
- Repository documentation and contribution templates.
- GitHub Pages preparation.
- MIT License.
